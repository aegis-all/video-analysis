# 動画分析（VIDEO ANALYSIS）

動画をアップロードするだけで、スクリーンショットの生成・配置まで自動で行い、
そのまま動画を見ながらフィードバックを書ける Web アプリです。

スプレッドシートでの運用をそのまま Web に移したものです。

| # | スクショ | 時間 | テキスト（素） | フィードバック（上司） |
|---|---|---|---|---|
| 1 | 🖼 | 00:00 | | |
| 2 | 🖼 | 00:01 | | |

---

## 1. 準備（初回だけ）

```powershell
cd C:\Users\AI\video-review
python -m pip install -r requirements.txt
```

スクリーンショット生成には別フォルダの `auto_screenshot.py` を使います。
そちらの依存（opencv-python / numpy）も入っている必要があります。

```powershell
python -m pip install -r C:\Users\AI\shorts-ad-analyzer\requirements.txt
```

### 証明書を作る（https にする場合）

```powershell
python make_cert.py
```

`data\cert\` に証明書ができ、次回から `https://` で起動します。
自分で作った証明書なので、**初回だけブラウザが警告を出します**
（「詳細設定」→「localhost にアクセスする」で進めます）。
これは、この PC・社内 LAN で使う場合の話です。
インターネットに公開するときは警告の出ない証明書を使います（[DEPLOY.md](DEPLOY.md)）。

## 2. 起動

このアプリは**サーバーが動いている間だけ**開けます。
プログラムを止めるとリンクも開けなくなります。

| ファイル | 何が起きるか | おすすめの場面 |
|---|---|---|
| **`start_hidden.vbs`** | **黒い画面を出さずに**起動し、ブラウザも自動で開く | **普段はこれ** |
| `start.bat` | 黒い画面を出したまま起動（ログが見える） | 動きがおかしいとき |
| `stop.bat` | サーバーを止める | 終わるとき／作り直すとき |

どれも**ダブルクリック**するだけです。
`start.bat` と `start_hidden.vbs` は、古いサーバーが残っていても自動で止めてから起動します。

### 毎回起動するのが面倒なとき

1. `Win + R` を押して `shell:startup` と入力 → Enter
2. `start_hidden.vbs` を**右ドラッグ**でそこへ入れ、「ショートカットをここに作成」を選ぶ

やめたいときは、そのショートカットを削除してください。

### コマンドで起動する場合

```powershell
cd C:\Users\AI\video-review
python app.py
```

社内の他の PC からは「社内LANから」の URL で開けます。
初回起動時に Windows ファイアウォールの確認が出たら「アクセスを許可する」を選んでください。

> **Python のコードを直したときは再起動が必要です。**
> 画面（テンプレート・CSS・JS）は保存すればすぐ反映されますが、
> `app.py` などは**再起動しないと古いまま動き続けます**。
> 起動時に `app.py の更新日時` が表示されるので、それで新旧を判断できます。

## 3. ログイン

初めて開いたときは、**最初のユーザーを作る画面**が出ます。

1. ID とパスワードを決める
2. QR コードが出るので、スマートフォンの **Google Authenticator** で読み取る
3. アプリに出た 6 桁を入力する

次回からは **ID → パスワード → 6 桁のコード** の順で入ります。

- **24 時間でログインし直し**になります。
- パスワードを **5 回続けて間違える**と、10 分間ログインできなくなります。
- パスワードは保存時にハッシュ化されるので、DB を見ても元の文字列は分かりません。

### チームの人を増やす

画面右上の**「ユーザー」**から追加します。
追加された人は初回ログイン時に自分の QR が出るので、各自のスマートフォンで登録してもらいます。

同じ画面で、パスワードの変更・**2段階認証のやり直し**（機種変更でアプリを失った場合）・
削除ができます。自分自身と、最後の 1 人は削除できません。

### スマートフォンを失くした / 機種変更した

他のユーザーに「ユーザー」画面から**2段階認証のやり直し**をしてもらってください。
次のログイン時に QR が出るので、読み取り直します。

**全員がログインできなくなった場合**は、この PC で次を実行するとユーザーが消え、
最初の設定からやり直せます（案件のデータは消えません）。

```powershell
python -c "import sqlite3; c=sqlite3.connect(r'data\app.db'); c.execute('DELETE FROM users'); c.commit()"
```

## 4. 使い方

1. ブラウザで開く
2. **ジャンル・案件名・案件番号**などを入力
3. **動画ファイル**を選ぶか、**動画の URL** を貼って「アップロードして開始」
   - 動画なしでも作れます（空の行が 30 行できます）
4. 「動画を処理しています…」と進捗が出る（60秒の動画で 20 秒ほど）
5. 完了すると、動画プレイヤーとスクショ一覧が自動で表示される
6. 「テキスト（素）」「フィードバック（上司）」を入力する
   - **保存ボタンはありません。**入力欄から離れると自動保存されます
   - 枠が緑になれば保存完了、赤なら失敗（画面右下に理由が出ます）
7. **スクショや時間ボタンをクリック**すると、動画がその時間へジャンプして一時停止します
8. スクショをクリックすると拡大表示（Esc または画面クリックで閉じる）

### 便利な操作

| したいこと | やり方 |
|---|---|
| リンクを人に渡す | 案件ページ左上のボタン。**貼り付けると案件名がリンクになります**（スプレッドシート可） |
| 行を消す | 行番号を**右クリック**。複数選びたいときはチェックを付けてから |
| 消した行を戻す | 削除直後に出る「元に戻す」 |
| 行を足す | 表の一番下の **＋** |
| 列の幅を変える | 見出しの境目をドラッグ |
| ジャンル・担当者で絞る | 一覧でジャンル名／担当者名をクリック |
| 案件ページへ行く | **案件名**をクリック（他の場所を押しても移動しません） |

## 5. 構成

```
video-review\
├── app.py            Flask 本体（画面とAPI）
├── auth.py           ログイン・ユーザー管理
├── db.py             SQLite のスキーマと接続
├── jobs.py           auto_screenshot.py を呼ぶバックグラウンド処理
├── config.py         設定（保存先・検出パラメータ・ポートなど）
├── make_cert.py      自己署名の証明書を作る
├── serve.py          プロキシの後ろに置くときの起動（waitress）
├── templates\        画面
├── static\           CSS / JavaScript
├── start_hidden.vbs  起動（普段はこれ）
├── start.bat         起動（ログを見たいとき）
├── stop.bat          停止
└── data\             ← ここにすべて保存されます
    ├── app.db            SQLite データベース
    ├── secret_key        ログイン状態の署名鍵（消すと全員ログアウト）
    ├── cert\             https の証明書
    ├── app.log           ログ
    ├── server.log        画面を出さずに起動したときの出力
    ├── videos\{id}\      アップロードした動画
    ├── screenshots\{id}\ 生成されたスクショ + index.json
    └── trash\            削除したスクショの置き場（戻すため）
```

### データベース

```
users       (id, username, password_hash, totp_secret, totp_enabled,
             fail_count, locked_until, created_at, last_login_at)
projects    (id, genre, name, project_no, slug, assignee,
             column_widths, created_at, updated_at)
videos      (id, project_id, version_label, original_name, file_path,
             source_url, duration_sec, status, progress, stage,
             error_message, sort_order, created_at)
screenshots (id, video_id, seq, image_path, timestamp_sec, row_height,
             text_raw, feedback_boss, ... , updated_at)
```

フィードバックはスクリーンショットと 1 対 1 なので、別テーブルにせず
`screenshots` に持たせています。

### バックアップ

`data` フォルダをコピーするだけで全部バックアップできます。
**`app.db` と `screenshots\` が失われると復旧できません。**

## 6. 設定

`config.py` を編集します。環境変数でも上書きできます。

| 項目 | 既定 | 説明 |
|---|---|---|
| `AUTO_SCREENSHOT_PY` | `C:\Users\AI\shorts-ad-analyzer\auto_screenshot.py` | スクショ生成スクリプトの場所 |
| `SCREENSHOT_ARGS` | `--telop-sensitivity 0.10 --min-gap 0.2 --format jpg --max-width 540` | 検出設定 |
| `PORT` | `5000` | ポート番号 |
| `MAX_UPLOAD_MB` | `2048` | アップロード上限 |
| `JOB_TIMEOUT_SEC` | `1800` | スクショ生成の打ち切り時間 |
| `DATA_DIR` | `data` | 保存先 |

**スクショが多すぎる／少なすぎる場合**は `SCREENSHOT_ARGS` を調整してください。
各パラメータの意味は `C:\Users\AI\shorts-ad-analyzer\README.md` の
「5. 感度調整」にまとめてあります。

## 7. 困ったとき

### 起動できない（ModuleNotFoundError）
```powershell
python -m pip install -r requirements.txt
```

### ブラウザが「安全ではありません」と出る
自分で作った証明書のためです。この PC・社内で使う分には問題ありません。
警告を出したくない場合は、正式な証明書が要ります（[DEPLOY.md](DEPLOY.md)）。

### ログイン画面すら出ない／真っ白
`stop.bat` → `start.bat`（黒い画面が出る方）で起動して、表示されるエラーを見てください。
画面を出さずに起動していた場合は `data\server.log` に同じ内容が残っています。

### 「スクショ生成スクリプトが見つかりません」と出る
`auto_screenshot.py` を移動した場合は `config.py` の `AUTO_SCREENSHOT_PY` を直してください。

### 「スクリーンショットの生成に失敗しました」と出る
画面にそのままエラー内容が表示されます。「もう一度実行する」で再試行できます
（**入力済みのテキストは連番をキーに引き継がれます**）。

### 社内の他の PC から開けない

**アドレスは `https://192.168.11.5:5000/` です。**
`https` を付けずに `192.168.11.5:5000` と打った場合も、
自動で `https` に切り替わるようにしてあります。

それでも開かないときは、

1. Windows ファイアウォールで Python の受信を許可する
2. 同じネットワークにいるか確認する
3. 起動時に表示された IP アドレスを使う（`localhost` は自分の PC 専用です）

なお、**他の PC でも初回だけ証明書の警告が出ます。**
「詳細設定」→「192.168.11.5 にアクセスする」で先に進めます。
毎回出るのが煩わしい場合は、`data\cert\server.crt` をその PC にコピーし、
ダブルクリック →「証明書のインストール」→「ローカル コンピューター」→
「信頼されたルート証明機関」に入れると出なくなります。

### ポート 5000 が使われている
```powershell
$env:VR_PORT="5050"; python app.py
```

### 動画が再生されない
ブラウザが再生できない形式（一部の .avi / .mkv など）の可能性があります。
スクショの生成自体は成功しているので、表とコメント欄は通常どおり使えます。
確実に再生したい場合は mp4（H.264）を使ってください。

### 同時に編集したら
2 人が同じ欄を同時に編集すると、**後に保存したほうが残ります**。
リアルタイム同期は行っていません。別の欄であれば問題ありません。
